# Source Data

This folder contains the canonical baseline workbook, `SCD2_Stored_Procedure_Sample_Data.xlsx`, used as the current source data for the planned Microsoft Fabric SCD Type 2 Customer Dimension demo. Its schema, data-quality considerations, mapping assumptions, and planned ingestion process are documented in [`docs/source-data.md`](../../docs/source-data.md).

Future source datasets must preserve the baseline workbook and include documentation describing their origin and intended load sequence.

Do not place production data, personal information, secrets, or connection details here.
