# Microsoft Fabric

The implemented and verified Microsoft Fabric environment is in workspace `WS_SCD2_Dev`. It includes Dataflow Gen2 `DF_SCD2_Staging`, Lakehouse `LH_SCD2_Staging` with `dbo.Customers` and `dbo.Sales`, Warehouse `WH_SCD2`, table `dbo.DimCustomer`, and stored procedure `dbo.usp_LoadDimCustomer_SCD2`.

This folder remains reserved for future versioned Microsoft Fabric artifact definitions, configuration guidance, and deployment notes. No exported Microsoft Fabric object definitions currently exist in the repository.

`FactSales`, pipeline orchestration, source-deletion handling, Power BI assets, and production hardening remain planned.
